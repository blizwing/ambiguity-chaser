# ambiguity-chaser

A LangGraph agent that reasons over a requirement set to catch cross-requirement
ambiguity and contradiction, the class of problem [eval-harness](https://github.com/blizwing/eval-harness)
found structurally out of reach for a per-requirement judge.

Phase 2 of a three-project, six-month plan moving from AI Quality into agentic
GenAI engineering. Sep to Nov 2026.

Build log and day-by-day notes to follow once work starts.
